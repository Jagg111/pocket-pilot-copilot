# Pocket Pilot's Copilot

A companion app for the mobile game **Pocket Pilots** by Nimblebit.

> Unofficial fan project. Not affiliated with or endorsed by Nimblebit.

## Status

Early setup. Technical seed notes will live in [`docs/`](docs/), and the app will be planned and built using the [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD).

## Working with BMAD

BMAD skills are installed for Claude Code (`.claude/skills`) and Codex (`.agents/skills`). From the project folder, launch your agent and invoke the `bmad-help` skill to see what to do next.

- `_bmad/` – BMAD configuration and assets
- `_bmad-output/` – planning and implementation artifacts
- `docs/` – long-term project knowledge and seed technical notes

## Seed documents

- [`docs/pocket-pilots-api-notes.md`](docs/pocket-pilots-api-notes.md) – observed notes on the Pocket Pilots web API (unofficial, undocumented, may change)
